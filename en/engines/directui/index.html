DirectUI and duixml Format

DirectUI is a windowless UI rendering engine that draws all control elements within a single window context without creating individual system handles (HWNDs), managing its own component tree, positioning, animation, and input event dispatching.

Note that, at this stage, this article contains a manually written dump of various data from the duixml markup format used by this engine; much remains unexplored, and the lists are incomplete.
