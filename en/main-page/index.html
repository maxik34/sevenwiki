Welcome to the Seven Wiki

This is an independent fan-project dedicated to the detailed study of Windows 7. It contains technical details about the system's design, modifications, and history.

Some Notes

Right now, the site is in its early stages, so it is currently more of a concept than a wiki. I think once I implement search, a new site builder, and a decent number of articles, it can be considered a wiki. In the meantime, I hope you like the site's style; I decided to rely on my own style rather than the Aero style—after all, this is a technical wiki, not one focused on aesthetics (though who knows…).

Main (future) sections

  • System: NT 6.1 kernel architecture, registry operations, and system calls.
  • Interface: Aero Glass, Explorer customization, and visual styles.
  • Deployment: Working with .WIM images, bootloaders, and installation automation.
  • Components: Overview of built-in applications and libraries (DLLs).
